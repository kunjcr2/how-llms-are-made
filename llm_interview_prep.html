How does Self-Attention work at a high level?
Click to reveal answer
TRANSFORMER
Self-attention allows each token in a sequence to "attend" or weight its relationship with every other token. It computes Queries (Q), Keys (K), and Values (V) through linear transformations, then uses dot-product similarity (Q @ K.T) to create an attention map. This map determines how much of each Value (V) contributes to the final context vector for a given token.
